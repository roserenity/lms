# Tenant Feature List

Features available within a tenant environment, organized by role and functional area.

---

## Admin

### Dashboard
- Summary metrics (enrollments, users, courses, completers)
- Pie charts for course completion and user distribution
- Course overview with enrollment counts
- Course users and completers tracking
- Custom registration field data visualization
- Export dashboard data (courses, users, completers)

### User Management
- List, search, and filter users (by role, status, date range)
- Bulk user import via CSV
- View import logs, filter, and delete
- Assign and update user roles
- Activate / deactivate users
- Export users

### Course Enrollment Management
- List and filter enrollments
- Enroll a single user into multiple courses
- Bulk enrollee import via CSV
- Remove individual enrollments
- Manage enrollment invoices
  - Update invoice status (pending / approved / rejected)
  - Update payment type (self-pay / company-pay / sponsorship)
  - Update participant type (regular / nominee / scholar)
  - Upload proof of payment, commitment letter, prime requirements
- Export invoices and invoice details
- LBP Official Receipt status check

### Class Categories
- Create, edit, list, and delete class categories

### Announcements
- Create, edit, view, and delete announcements
- Filter announcements by course and date range
- Manage announcement comments

### Forum Management
- Create, edit, view, and delete forum posts and comments
- Manage banned words list (view, add, update, bulk save)

### Tickets & Support
- View and update ticket status
- View ticket messages
- Track ticket counts
- Export tickets

### Communication
- Private chat: contact list, view and send messages, download attachments
- Group chat: create, add/remove users, update/remove photo, view messages, send messages, download attachments

### Customization & Settings
- Custom table management: create, view, modify columns (add, delete, update, reorder)
- Custom module field settings: view, add, update, delete
- Custom registration page and field management
- Training credits management
- Certificate template category management
- Page asset management

### Landing Page Management
- Upload, view, and delete landing page background images

### Document Management
- Create, update, and view documents

### Activity Logs
- View activity log with pagination
- View event statistics by type
- Export activity logs

### Advisories
- Create, edit, view, and delete advisories

### Exports
- View and manage export history
- Download exported files
- Delete export records

### Account Settings
- View and edit profile
- Change password

---

## Instructor

### Course Management
- Create, edit, publish, unpublish, and delete courses
- Upload and remove course images
- Duplicate courses
- Restore soft-deleted courses
- Share courses with other instructors (grant / revoke access)
- Set certificate templates per course
- Tag class categories to courses
- Manage training credits for courses

### Module Management
- Create, edit, view, delete, and reorder modules
- Update module validity period
- Sync module prerequisites
- Manage custom module fields
- Reorder module contents

### Topic & Sub-topic Management
- Create, edit, view, delete, and reorder topics
- Create, edit, view, delete, and reorder sub-topics

### Learning Materials
- Upload and manage learning materials per topic/sub-topic
- Supported types: documents, videos, attachments, SCORM packages

### SCORM Content
- Monitor SCORM upload progress
- Update SCORM preview links
- View SCORM course summary
- View and export SCORM learner list and progress
- View SCORM learner interactions and submissions
- Manage SCORM activity questions and respondents
- Export SCORM activity answers and respondents
- Manage SCORM registrations

### Assessment Management
- Create, edit, view, and delete assessments
- Add, edit, delete, and reorder questions
- Upload and delete question images
- Tag user access per assessment
- Duplicate assessments
- Move assessments across courses
- Share assessments with other instructors (grant / revoke access)
- Export assessment responses (list and summary formats)

### Question Pools
- Create, edit, view, and delete question pools
- Add, edit, and delete questions within pools
- Upload and delete question images
- Assign question pools to assessments and evaluations

### Rubric Management
- Create, edit, view, and delete rubrics
- Manage criteria, rating scales, and rating indicators
- Share rubrics with other instructors (grant / revoke access)

### Grading
- View grading dashboard with assessment details
- View student assessment responses
- Update grading scores
- Update grading status (course evaluation, module evaluation, assessment)
- Auto-check assessment answers
- View and update group activity group grading status

### Course & Module Evaluations
- Create, edit, view, and delete course and module evaluations
- Manage evaluation questions (create, delete, reorder, upload images)
- Update evaluation validity
- View respondents, attempts, and answers
- Mark responses as reviewed
- Export evaluation responses (list and summary formats)
- Assign question pools to evaluations

### Enrollment Management
- View course enrollments and enrollee list
- Manual enrollment of users
- Upload proof of payment, commitment letter, and prime requirements for manual enrollment
- Export course invoices

### Student Progress Tracking
- View enrollee overall progress and course progress details
- View enrollee Zoom meeting attendance
- Mark topics and sub-topics as completed for a student
- View student assessments, records, and overall grading
- Export enrollees list

### Zoom Meeting Management
- View course Zoom meetings and participants
- Update participant attendance
- Export participant list
- View and update specific participant details

### Group Activities
- Create, edit, and delete group activities
- View and delete group activity groups
- Generate group activity group files
- Add and remove members from groups

### Course Groups
- Create, edit, and delete course groups
- Add and remove members
- Create group chats within course groups

### Certificate Management
- Create and manage certificate templates (upload, edit, delete, duplicate)
- Assign and generate certificates for students
- View course certificate enrollees

### Communication
- Create, edit, and delete announcements and comments
- Private chat: contact list, view and send messages, download attachments
- Group chat: create, add/remove users, update/remove photo, view messages, send messages, download attachments
- Create and manage course-level group chats

### Forum
- Create, edit, view, and delete forum posts and comments

### Reports & Analytics
- Summary metrics: enrollee counts, courses, completers, assessment data
- Export: courses, completers, course users, assessment data, enrollees

### Activity Logs
- View activity log with pagination and statistics
- Export activity logs

### Exports
- Create, view, download, and delete exports
- Batch export multiple items

### Account Settings
- View and edit profile
- Change password

### Announcements
- View course and system announcements
- Create, edit, and delete own comments

### Forum
- Create, edit, and delete own forum posts

- View all forum discussions

### Communication
- Private chat: view contacts, send messages, download attachments

### Tickets & Support
- Create support tickets
- Submit and view ticket messages
- View help desk

### Zoom Meetings

### Calendar

### Account Settings
- View and edit profile

- View transaction history
